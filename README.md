# Aim Trainer

VALORANTのエイム練習用に制作した、ブラウザで遊べるエイムトレーナーです。
実際のゲームで使っている感度設定を反映できるようにしています。

## 機能

### ゲームモード
- **Stage1 - Normal**：静止した的を撃つ
- **Stage2 - Moving**：左右に動く的を撃つ。スコアが上がるほど的が加速する

### 実装した機能
- Raycastによる射撃判定（クロスヘア中心と判定点が一致）
- 制限時間・スコア・リザルト表示
- 感度／BGM音量／効果音音量の設定画面
- 設定値のシーン間共有（static変数による保持）
- 日本語フォント対応（TextMeshPro）

## 工夫した点

### 難易度の上限設定
Stage2 ではスコアに応じて的の移動速度が上がる仕様にしたが、
速度が青天井だとプレイ不能になるため上限値を設けた。

### 設定値をシーン間で保持する仕組み
音量や感度の設定がシーン遷移でリセットされる問題があった。
static 変数で値を保持することで、
メインメニューで変更した設定がステージにも反映されるようにした。


### 苦労した点

Unity を扱うのが初めてだったため、
エディタの操作や各機能の役割を理解するのに時間がかかった。
特に景観制作では、Kenney のアセットを組み合わせる際に
オブジェクトの配置のズレや、モデルを拡大するとテクスチャが
崩れる問題に直面し、グリッドスナップの利用やタイルを並べる方法で対応した。
